# DummyL-Robot 通信协议文档（Zeta 电机 / Modbus RTU）

> 本文档描述 DummyL-Robot 六轴机械臂与 Zeta 电机之间的通信协议，
> 供 comm / control 层实现与硬件联调参考。
> 内容基于 Zeta 产品手册（`external/` 目录）整理。

---

## 1. 物理层

| 项目 | 值 |
| --- | --- |
| 接口 | RS485 半双工总线（USB-RS485 转接） |
| 波特率 | 115200 |
| 数据位 / 校验 / 停止位 | 8N1 |
| 主从结构 | 1 主机（PC 控制台） + N 从机（Zeta 电机） |
| 帧间隔 | 主机发送后需等待从机响应；帧间留出静默间隔（≥ 3.5 字符时间） |

---

## 2. 帧格式（Modbus RTU）

### 2.1 请求帧（主机 -> 电机）

| 字节 | 内容 | 说明 |
| --- | --- | --- |
| 0 | 从站地址 | 1 字节，默认 1（寄存器 0x00E0 可读写） |
| 1 | 功能码 | 03H 读 / 06H 写单寄存器 / 10H 写多寄存器 |
| 2..N | 数据 | 依功能码而定 |
| N+1 | CRC16 低字节 | 多项式 0xA001，LSB 在前 |
| N+2 | CRC16 高字节 | |

### 2.2 响应帧（电机 -> 主机）

- **正常响应**：回显从站地址 + 功能码，随后为读数据（03H）/ 寄存器地址回显（06H、10H）。
- **异常响应**：功能码最高位置 1（0x80 | 原功能码），后跟 1 字节异常码。

### 2.3 CRC16 计算（0xA001）

1. 初值 `0xFFFF`；
2. 每个字节与 CRC 低字节异或；
3. 右移 8 次，每次若最低位为 1 则异或 `0xA001`；
4. 结果低字节在前、高字节在后附到帧尾。

```c
uint16_t crc16_modbus(const uint8_t *data, size_t len) {
    uint16_t crc = 0xFFFF;
    for (size_t i = 0; i < len; i++) {
        crc ^= data[i];
        for (int b = 0; b < 8; b++) {
            if (crc & 1) crc = (crc >> 1) ^ 0xA001;
            else         crc >>= 1;
        }
    }
    return crc;
}
```

### 2.4 步数换算

```
步数 = 角度° × 减速比 ÷ 360 × 16384
角度° = 步数 × 360 ÷ (减速比 × 16384)
```

编码器单圈 16384 步（手册 P3-6 硬件参数：自带绝对式磁感应编码，精度每圈
16384 步；P14 寄存器 0x00E3 每圈步数出厂 0x0640=1600 仅用于脉冲控制细分，
RS485 无细分、固定一圈 16384 步）。手册 P13 示例：0x00004000 = 16384 步、
0xFF FFC0 00 = -16384 步（有符号 32 位，补码）。

> 注意：减速比（42/50:1、42/100:1、35/50:1、28/50:1）来自项目需求侧指定，
> 产品手册中未提供各轴减速比参数。

## 3. 功能码与帧示例

### 3.1 03H 读保持寄存器

请求：`从站 功能码 起始地址(2B) 数量(2B) CRC(2B)`

| 示例 | 说明 |
| --- | --- |
| `01 03 00 00 00 01 84 0A` | 读地址 0x0000，1 个寄存器（状态字） |
| `01 03 00 01 00 02 95 CB` | 读地址 0x0001，2 个寄存器（实际步数高/低） |
| `01 03 00 00 00 03 05 CB` | 读地址 0x0000，3 个寄存器（状态 + 步数） |

正常响应：`从站 功能码 字节数(1B) 数据(2B×N) CRC(2B)`

例：`01 03 02 00 01 79 84` = 状态字 0x0001（运行中）。

读设备地址（P16 示例，使用广播地址 00，电机不回显具体地址则仍回 0x00E0 值）：

| 帧 | 说明 |
| --- | --- |
| 发 `00 03 00 E0 00 01 84 2D` | 广播读设备地址（地址 0x00E0，1 个寄存器） |
| 回 `00 03 02 00 01 44 44` | 设备地址 = 0x0001（出厂默认 1） |

### 3.2 06H 写单个寄存器

请求：`从站 06H 寄存器地址(2B) 数据(2B) CRC(2B)`

例：`01 06 00 06 00 01` + CRC = 写使能寄存器 0x0006 = 1（使能）。

正常响应：原帧回显。

### 3.3 10H 写多个寄存器

请求：`从站 10H 起始地址(2B) 数量(2B) 字节数(1B) 数据(2B×N) CRC(2B)`

位置模式示例（P16 原文，从 0x0010 起连续写 6 个寄存器）：

```
01 10 00 10 00 06 0C
  00 19 | 00 00 | 00 00 | 13 88 | 00 00 | 00 00
  CRC(2B)
```

| 地址 | 值 | 说明 |
| --- | --- | --- |
| 0x0010 | 0x0019 | 目标步数高位（目标 0x00190000 = 1638400 步 = 100 圈） |
| 0x0011 | 0x0000 | 目标步数低位 |
| 0x0012 | 0x0000 | 保留（须占位） |
| 0x0013 | 0x1388 | 目标速度 5000 rpm |
| 0x0014 | 0x0000 | 加速度（写 0 表示使用默认值 0xE8） |
| 0x0015 | 0x0000 | 精度（写 0 表示使用默认值 0xE9） |

正常响应：`从站 10H 起始地址(2B) 数量(2B) CRC(2B)`。

速度模式示例（P16 原文，从 0x0060 起连续写 4 个寄存器）：

```
01 10 00 60 00 04 08
  00 00 | 13 88 | 00 FA | 00 00     <- 保留、速度 5000rpm、加速度 250rpm/s、保留
  CRC(2B)
```

| 地址 | 值 | 说明 |
| --- | --- | --- |
| 0x0060 | 0x0000 | 保留（须占位） |
| 0x0061 | 0x1388 | 速度模式目标速度 5000 rpm（有符号，负值反转） |
| 0x0062 | 0x00FA | 加速度 250 rpm/s |
| 0x0063 | 0x0000 | 保留（须占位） |

反转示例：`01 10 00 60 00 04 08 00 00 EC 78 00 FA 00 00` + CRC（0xEC78 = -5000，补码）。

停止示例（P16 原文，写 0x0000 到 0x0004）：

```
01 10 00 04 00 01 02 00 00 A7 D4
```

> ⚠️ **手册内部冲突**：P13 寄存器表 0x0004 写「往寄存器写 1 立马停止」，
> 但 P16 示例帧实际用 10H 写入 0x0000 实现停止。本工程以示例帧为准
> （写 0x0000 停止），并在联调时与厂商确认。

## 4. Zeta 寄存器表（手册 P13-15 完整整理）

### 4.1 运行状态区（0x0000~0x00FF，03H 读 / 06H、10H 写）

| 地址 | 名称 | 读写 | 出厂值 | 说明 |
| --- | --- | --- | --- | --- |
| 0x0000 | 状态字 | 03H 读 | 00 00 | 0=待机/到位 1=运行 2=碰撞停 3=正光电停 4=反光电停 |
| 0x0001 | 实际步数（高） | 03H 读 | 00 00 | 有符号 32 位补码，步数 = 高位<<16 \| 低位 |
| 0x0002 | 实际步数（低） | 03H 读 | 00 00 | 例 00 00 40 00 = 16384；FF FF C0 00 = -16384 |
| 0x0003 | 实际速度 | 03H 读 | 00 00 | 例 0B B8 = 3000 rpm |
| 0x0004 | 急停指令 | 03/06/10H | 00 00 | 表注「写 1 立马停止」；P16 示例写 0x0000 停止（冲突，以示例为准） |
| 0x0005 | 电流 | 03H 读 | 00 00 | 单位 mA，例 01 F4 = 500 mA |
| 0x0006 | 失能 | 03/06/10H | 00 01 | 1=使能，0=失能（出厂默认使能） |
| 0x0007 | 输出指令 | 03/06/10H | 00 00 | 0~1000，对应 K 引脚 PWM 占空比 0~100.0% |
| 0x0008 | 限位开关 | 03/06/10H | 00 01 | 0=不起作用，1=起作用（出厂默认作用） |
| 0x0010 | 目标步数（高） | 03/06/10H | 00 00 | 位置模式目标步数高位 |
| 0x0011 | 目标步数（低） | 03/06/10H | 00 00 | 位置模式目标步数低位 |
| 0x0012 | 保留 | - | - | 位置模式连续写帧中须占位 |
| 0x0013 | 速度 | 03/06/10H | 00 00 | 位置模式目标速度 rpm，例 0B B8 = 3000；上电读取 0xE7 作为默认值 |
| 0x0014 | 加速度 | 03/06/10H | 00 00 | 0~30000 rpm/s；上电读取 0xE8 作为默认值 |
| 0x0015 | 精度 | 03/06/10H | 00 00 | 例 100：实际步数与目标相差 ≤100 即到位；上电读取 0xE9 作为默认值 |
| 0x001F | 归零指令 | 03/06/10H | 00 00 | 写入值 = 归零速度；正数正转、负数反转；含堵转停止与限位停止 |
| 0x0020 | 单圈目标步数（高） | 03/06/10H | 00 00 | 单圈绝对值模式 |
| 0x0021 | 单圈目标速度 | 03/06/10H | 00 00 | 单圈绝对值模式 |
| 0x0022 | 模式选择 | 03/06/10H | 00 00 | 0=就近原则（默认），1=正常顺时针原则 |
| 0x0040 | JOG 目标步数（高） | 03/06/10H | 00 00 | JOG 模式 |
| 0x0041 | JOG 目标步数（低） | 03/06/10H | 00 00 | JOG 模式 |
| 0x0042 | 保留 | - | - | - |
| 0x0043 | JOG 速度 | 03/06/10H | 00 00 | 上电读取 0xE7 作为默认值 |
| 0x0044 | JOG 加速度 | 03/06/10H | 00 00 | 上电读取 0xE8 作为默认值 |
| 0x0045 | JOG 精度 | 03/06/10H | 00 00 | 上电读取 0xE9 作为默认值 |
| 0x0060 | 保留 | - | - | 速度模式连续写帧中须占位 |
| 0x0061 | 速度模式速度 | 03/06/10H | 00 00 | 目标速度 rpm（有符号，负值反转）；上电读取 0xE7 作为默认值 |
| 0x0062 | 速度模式加速度 | 03/06/10H | 00 00 | 上电读取 0xE8 作为默认值 |
| 0x0063 | 保留 | - | - | - |

### 4.2 电机参数区（0x00E0~0x00F1，03H 读 / 06H、10H 写）

| 地址 | 名称 | 读写 | 出厂值 | 说明 |
| --- | --- | --- | --- | --- |
| 0x00E0 | 设备地址 | 03/06/10H | 00 01 | 从站地址，出厂 1；读写示例见 §3.1 |
| 0x00E1 | 堵转电流 | 03/06/10H | 0B B8 | 例 0B B8 = 运动电流 3000mA，达到该电流一段时间判定堵转；范围 0~3000mA |
| 0x00E2 | 找零电流 | 03/06/10H | 02 58 | 例 02 58 = 600mA，找零（回零）时使用 |
| 0x00E3 | 每圈步数 | 03/06/10H | 06 40 | 例 06 40 = 1600 步（脉冲控制细分）；RS485 无细分，固定一圈 16384 |
| 0x00E4 | 底层方向 | 03/06/10H | 00 01 | 方向设置 |
| 0x00E5 | 堵转逻辑 | 03/06/10H | 00 00 | 00=泄力（堵转断电），01=人机对抗（保持力矩、持续发热） |
| 0x00E6 | 堵转时间 | 03/06/10H | 00 00 | 单位 ms，超过认为堵转并报堵转错误（出厂 0，需实机整定） |
| 0x00E7 | 默认速度 | 03/06/10H | 未标注 | 上电赋给 0x0013/0x0043/0x0061 |
| 0x00E8 | 默认加速度 | 03/06/10H | EA 60 | 上电赋给 0x0014/0x0044/0x0062（出厂值 0xEA60 与 0x0014 范围 0-30000 存在疑点，联调时确认） |
| 0x00E9 | 默认精度 | 03/06/10H | 00 64 | 例 00 64 = 100，上电赋给 0x0015/0x0045 |
| 0x00EA | 波特率（高 16 位） | 03/06/10H | 00 01 | 与 0x00EB 组成 32 位波特率 |
| 0x00EB | 波特率（低 16 位） | 03/06/10H | C2 00 | 例 00 01 C2 00 = 115200 |
| 0x00EC~0x00EF | 保留 | - | - | - |
| 0x00F0 | 版本号 | 03H 读 | 00 1F | 例 00 1F = 3.1 |
| 0x00F1 | 型号 | 03H 读 | - | 电机型号 |

> 持久化说明：手册仅对 0x00D5（设置零位，标注「此值为掉电保存」）与
> 0x00E7~0x00E9（上电读取作为默认值）给出非易失依据，0x00E0 设备地址等
> 参数寄存器**无明文持久化说明**。修改 0x00E0 后是否掉电保存请联调时与
> 厂商确认。

### 4.3 使能 / 去使能

- 使能：写 0x0006 = 0x0001（出厂默认已使能）；
- 失能：写 0x0006 = 0x0000；
- 停止：写 0x0004（见 §3.3 停止示例，写 0x0000，与表注「写 1」冲突，以示例为准）；
- 状态：轮询 0x0000，2=碰撞停、3=正光电停、4=反光电停 均需人工处理后再恢复。

### 4.4 堵转判定（手册 P3-6 + P14-15）

堵转由「电流 + 速度 + 时间」共同决定：电机电流达到 0x00E1 堵转电流阈值
且（低速/堵转状态）持续 0x00E6 堵转时间后，判定堵转并置状态字；堵转后行为
由 0x00E5 决定（泄力断电 / 人机对抗保持力矩）。

## 7. 控制时序建议（骨架）

1. 上电：依次写 0x0006=1 使能（出厂默认已使能）；
2. 回零：写 0x001F（归零速度，正转/反转），分组并行执行；
3. 运动：位置模式连续写 0x0010~0x0015（目标步数 + 速度 + 加速度 + 精度）；
4. 监控：轮询 0x0000（状态）与 0x0005（电流），对照 0x00E1 阈值判堵转；
5. 停机：写 0x0004=0 停止；需要时写 0x0006=0 失能。
